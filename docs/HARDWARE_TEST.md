# Проверка на устройствах — блок А

**Статус: сборки и автоматические проверки пройдены; на железе не подтверждено.**
Следующие видеоблоки не реализованы.
Использовать только последнюю полностью зелёную сборку; не считать её готовым продуктом. APK и Setup.exe берутся
из одного зелёного запуска Actions или соответствующего предварительного Release.
Нужны Poco X3 NFC, OPPO Reno 15 и Windows 11 x64. Проверить каждый телефон отдельно.

1. Установить APK. Открыть Lenscast: тёмный интерфейс, две карточки, настройки.
   Проверить прокрутку и отсутствие наложений. На ПК установить Setup.exe:
   один запрос администратора, запуск через меню «Пуск», только русский интерфейс.
2. На телефоне открыть «Настройки» → «Настроить уведомления». Разрешить работу
   в фоне в системных настройках. Вернуться, нажать «Старт». Должны появиться
   код и постоянное уведомление с кнопкой «Стоп». Камера/микрофон не запрашиваются.
3. Подключить телефон к тому же роутеру, ПК оставить на Ethernet. На ПК нажать
   «Найти телефоны»: появляется карточка. Выбрать её, ввести код, подключиться.
   Если обнаружение блокируется роутером/брандмауэром, ввести IPv4 телефона вручную
   (Настройки Android → Wi-Fi → текущая сеть). При запросе брандмауэра Windows
   разрешить Lenscast только в частной домашней сети.
4. Должны появиться название телефона, заряд, зарядка, температура и тип сети.
   Подключить зарядку: статус меняется. На 2,4 ГГц должно быть предупреждение.
   Сравнить заряд с системным индикатором телефона. Записать, доступен ли диапазон.
5. Отключиться, подключиться без кода. Перезапустить Windows-приложение и повторить:
   код не нужен. На втором телефоне повторить первичное сопряжение. Убедиться,
   что после этого можно снова подключить первый телефон без нового кода.
6. Выключить Wi-Fi телефона на 10 секунд, включить. После восстановления сети
   соединение должно восстановиться без кода. На телефоне уведомление не исчезает.
   Проверить также сворачивание приложения и ожидание 5 минут.
7. Нажать «Забыть телефон» на ПК. Следующее соединение требует код. Ввести 5
   неверных кодов: появляется ограничение попыток, правильный код принимается
   только после паузы. Проверить смену кода на телефоне.
8. Подключить кабель, включить отладку USB, подтвердить доверие ПК на телефоне.
   На ПК «Проверить USB» → выбрать карточку USB → «Подключиться» без кода.
   В состоянии отображается USB. Повторить с выключенным Wi-Fi телефона.
   При двух USB-телефонах приложение просит оставить один.
9. Нажать «Остановить на телефоне» на вкладке «Экран». Уведомление должно
   исчезнуть. Повторить запуск и остановку кнопкой в уведомлении.
10. Проверить окно ПК 760×580 и 1120×800, масштаб Windows 100/150/200%.
    Карточки и поля не перекрываются, длинные сообщения читаются с прокруткой.
    Передачи изображения пока **не должно быть**; действия будущих блоков отключены.
11. Сохранить журналы на обеих сторонах через настройки. Удалить Lenscast с ПК:
    файлы программы, ярлык, журнал и доверие должны удалиться. Установить снова:
    требуется новое сопряжение. На Android обновить APK той же подписью поверх:
    установка проходит без удаления приложения.

## Что прислать

Номер пункта, модель телефона и версию ОС; ожидаемое/фактическое поведение;
журнал с ПК и телефона; скриншот ошибки/раскладки. Для обнаружения — схема сети
(какой диапазон, есть ли гостевая сеть/изоляция клиентов). Для USB — текст
состояния, появилось ли системное окно доверия. Коды/токены не присылать.

## Ещё не проверено / границы блока

- APK/Setup проверяются CI отдельно; реальный запуск и удаление требуют устройств.
- Захват, жесты, камера, видеозадержка, виртуальная камера и работа с погашенным
  экраном относятся к следующим блокам и здесь не заявлены готовыми.
- Детальный онбординг MIUI/ColorOS и безопасные вендорные переходы — блок Д;
  в блоке А доступен стандартный переход в системные настройки приложения.

## Дополнительные проверки устойчивости связи

12. Пока ПК подключён по Wi-Fi, нажать «Остановить на телефоне»: команда должна
    сработать сразу, а не только после отключения сети. Это проверяет приём
    сообщений поверх TLS (не только одностороннюю телеметрию).
13. При работающем соединении несколько раз быстро отключиться и подключиться
    заново. Старое соединение не должно отключать новое; через несколько секунд
    связь и телеметрия должны стабилизироваться. В статусе допускается краткая
    занятость телефона, пока он обнаруживает закрытие предыдущего соединения.
14. Если роутер позволяет сменить DHCP-адрес телефона, сменить его и выбрать
    найденную карточку снова: для того же сертификата повторный код не нужен.
    При другом сертификате на ранее доверенном IP соединение, наоборот, отклоняется.
15. Проверить показатель «отклик связи»: это RTT канала управления, **не задержка
    изображения**. Измерение видеозадержки будет возможно только с видеопотоком.
