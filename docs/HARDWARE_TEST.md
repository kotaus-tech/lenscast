# Блок C · камера телефона · 0.3.1

A/B и исправление тапа 0.2.1 приняты пользователем. Проверять **только после полного
зелёного CI**, APK и Setup из одного Release. Установка поверх прежней версии,
без очистки данных. Пока это камера в Lenscast, **не системная веб-камера Windows**:
Windows Camera/Discord/Zoom/OBS и другие программы будут проверяться в D.

На каждом телефоне отдельно: Poco X3 NFC / Android 11 / MIUI и OPPO Reno15 /
Android 16 / ColorOS; по Wi-Fi и USB. Не приписывать одному результат второго.

## Запуск и изображение

1. Остановить связь на телефоне. Выбрать «Веб-камера», «Старт», подключить ПК.
   Нажать «Запустить камеру» на телефоне и разрешить CAMERA. Ожидается уведомление
   камеры; нет запроса микрофона, MediaProjection и специальных возможностей.
2. На ПК открыть «Веб-камера». Ожидается живой preview, правильные пропорции,
   реальные размеры/декодировщик, строка фактических FPS/ISO/выдержки. После появления
   кадров исчезает «режим ещё не подтверждён». Сфотографировать UI обоих устройств.
3. По очереди выбрать каждый предлагаемый модуль. Ожидается изменение картинки/FOV;
   подписи основаны на camera ID/фокусных расстояниях, не маркетинговых названиях.
   Скрытые OEM-модули и physical-only ID не обещаются. При отказе — понятное сообщение,
   повторный локальный запуск возвращает последний успешно сохранённый режим.
4. На каждом модуле попробовать низкое и высокое разрешение/FPS из списка.
   Во время пересборки возможна короткая пауза. Кадры должны возобновиться, размеры
   совпасть с выбранными. Список — заявленные аппаратурой кандидаты; фактический FPS
   может быть ниже диапазона из-за света/нагрева/кодировщика. Записать отказавшие
   сочетания, не считать их проверенными режимами.
5. Проверить поворот 0/90/180/270° и отражение. Меняются именно preview и metadata,
   разрешение кодированного потока остаётся sensor-native. Уменьшить окно до 760×580:
   элементы доступны прокруткой, не перекрываются. Между модулями параметры раздельны.

## Параметры камеры

6. Раскрыть «Фокус, экспозиция и баланс белого». Проверить каждый доступный элемент:
   масштаб, AF (однократный/непрерывный), ручной фокус после выбора AF OFF,
   экспокоррекцию при auto exposure, AE lock, WB presets/lock, фонарик. Ожидается
   видимый эффект, без потери потока; не поддерживаемые камерой элементы отсутствуют.
7. Раскрыть «Профи». Если доступны, проверить manual exposure/ISO/выдержку и один вид
   стабилизации. Для EV/ISO — целое число. Выдержка не выше периода выбранного FPS.
   EIS и OIS одновременно не включать. Фактические ISO/выдержку сравнить со строкой HAL;
   в auto они меняются самостоятельно. Неподдерживаемое значение не должно ронять поток.
8. Нажать «Сбросить настройки этой камеры». Ожидается автоматическая экспозиция,
   фокус по шаблону камеры, исходный поворот/отражение. Настроить снова, остановить
   камеру и запустить: успешные параметры этого модуля восстанавливаются. Проверить
   вторым телефоном: настройки одного не должны применяться к другому.

## Экран выключен / фон / переподключение

9. Оставить трансляцию камеры не менее **10 минут с выключенным дисплеем и включённой
   блокировкой**. С ПК менять масштаб, EV/другие доступные параметры. Кадры и управление
   должны продолжаться. Записать длительность, FPS, нагрев, прошивку. AVD не заменяет
   эту проверку на MIUI/ColorOS.
10. Если прошивка запрещает камеру под блокировкой: разблокировать, открыть Lenscast,
    запустить камеру, нажать «Чёрный экран». Ожидается почти чёрная поверхность с
    минимальной яркостью, возврат кнопкой «Вернуться». Проверить не менее 10 минут
    с управлением с ПК. Это честный fallback с включённым дисплеем, не обход keyguard.
11. Свернуть Lenscast, открыть другие НЕкамерные приложения. Кадры должны идти.
    Открытие другой камеры/отзыв CAMERA/переключатель privacy может штатно завершить
    захват: уведомление и ресурсы освобождаются, UI предлагает локальный повторный старт.
12. Отключить Wi-Fi/кабель на 10–20 с, восстановить. Камера на телефоне остаётся явно
    запущенной, ПК переподключается, получает новый ticket, preview возобновляется.
    После «Отключить»/закрытия ПК картинка и редакторы на ПК очищаются; камера телефона
    останавливается локально кнопкой/уведомлением или общей кнопкой «Стоп» связи.
13. Несколько раз остановить/запустить камеру, в том числе сразу после нажатия запуска.
    Ожидается освобождение камеры/кодировщика/wakelock, отсутствие зависшего открытия.
    Остановить связь, выбрать «Экран», повторить обычный тап/удержание/drag: всё как
    в принятом B, без Camera2 и camera privacy indicator в режиме экрана.

## Что прислать

14. Для каждой связки телефон/транспорт: что прошло, какие режимы и controls фактически
    доступны, отказы по пунктам, длительность screen-off/fallback, FPS/нагрев.
    Два журнала: Android «Настройки → Сохранить журнал», ПК «Настройки → Сохранить журнал».
15. При проблеме: номер пункта, последние 2–3 действия, время, скриншот PC/фото телефона
    (без кода сопряжения), оба журнала. По общему «работает» не фиксируем непроверенную
    10-минутную матрицу, точную задержку, HEVC или аппаратный decode/GPU.

В C нет записи, звука, облака, виртуальной MF-камеры или DirectShow. До приёмки C
не переходим к D и проверке Camera/Chrome/Edge/Discord/Telegram/Zoom/OBS.
