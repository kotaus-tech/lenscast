# Lenscast

Личный инструмент для Android и Windows 11 x64. Только тёмная тема, русский интерфейс.

## Текущее состояние

**Блок А в разработке, не готовый продукт.** Реализуется связь: оболочки,
сопряжение TLS, USB/adb, DNS-SD, переподключение и телеметрия. Передачи изображения,
жестов, управления Camera2 и виртуальной камеры пока нет. Соответствующие действия
в интерфейсе недоступны. Показатели видеозадержки не выдумываются.

## Получение сборки

В GitHub Actions открыть **«APK и установщик Windows»**, выбрать зелёный запуск
с нужным коммитом и скачать оба артефакта. Только после успешных Android и Windows
jobs появляется предварительный Release с `app-release.apk` и `Lenscast-Setup.exe`.
Красная сборка не считается результатом работы.

APK подписан постоянным личным ключом `android/lenscast.keystore` (PKCS12), alias
`lenscast`, пароль `lenscast-personal`. Ключ намеренно в репозитории по ТЗ. Он не
подходит для публикации или иных приложений. Не заменяйте его, иначе обновление
поверх приложения перестанет работать.

## Сборка

Android: JDK 17, Gradle 8.13, Android SDK 36, Build Tools 36.0.0.

```sh
cd android
gradle :app:assembleRelease :app:lintRelease
```

Windows: Windows 11 / Windows Server 2022, .NET SDK 8.0.415, Inno Setup 6.

```powershell
dotnet publish windows/Lenscast/Lenscast.csproj -c Release -o artifacts/windows
dotnet run --project tests/Lenscast.Tests -c Release
# Положить platform-tools 36.0.2 (adb.exe, две DLL, NOTICE.txt)
# в artifacts/windows/adb, как в workflow.
& "${env:ProgramFiles(x86)}/Inno Setup 6/ISCC.exe" installer/Lenscast.iss
```

## Установка и подключение

1. Установить APK на телефон, разрешив установку из выбранного источника.
2. Установить Setup.exe на Windows, подтвердив запрос администратора.
3. На телефоне открыть настройки Lenscast, разрешить уведомления и работу в фоне.
4. Нажать «Старт». На ПК найти телефон либо ввести IPv4 из настроек Wi-Fi.
5. При первом подключении ввести код с телефона. Далее используется сохранённое
   доверие (DPAPI на Windows, закрытые данные приложения и AndroidKeyStore на телефоне).

Первое сопряжение — только в доверенной домашней сети. Самоподписанный сертификат
не удостоверяет личность до проверки кода; это не PAKE. При смене сертификата
автоматическое соединение прекращается. Гостевая сеть и изоляция Wi-Fi-клиентов
могут блокировать обнаружение/подключение. ПК подключён к роутеру Ethernet.

### USB

В сведениях о телефоне нажать 7 раз на номер сборки (MIUI: версию MIUI), включить
«Для разработчиков → Отладка по USB». Подключить кабель с передачей данных,
подтвердить доверие этому ПК. В Lenscast на ПК нажать «Проверить USB», выбрать
карточку и подключиться. Код не нужен. При нескольких телефонах оставить один.
`adb` входит в установщик. Незашифрованный сервер доступен **только на loopback
телефона**, не в локальной сети.

## Журнал и удаление

На обеих платформах: «Настройки → Сохранить журнал». Windows хранит журнал и
защищённое доверие в `%LOCALAPPDATA%\Lenscast`; токены/коды не журналируются.
Удаление Windows-приложения убирает эту папку. На данном этапе регистрации COM
нет; она появится вместе с виртуальной камерой в отдельном блоке Г.
