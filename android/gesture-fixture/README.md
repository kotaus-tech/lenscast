# Только цель регрессии CI

Отдельное приложение без сетевых разрешений. Стандартная кнопка Android считает
OnClick, OnLongClick, ACTION_UP/MOVE и длительность MotionEvent. Команды приходят
через настоящий управляющий сокет Lenscast и AccessibilityService — сам fixture
не вводит события и не заменяет систему имитацией.

Не включается в APK Lenscast, Setup.exe или Release; устанавливается только на AVD.
Это не диагностический экран пользовательского приложения.
